# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-10

### Added
- Initial release
- Full ShadCN/Tailwind v4 support
- Light-mode and dark-mode variants
- Shadow tinting with brand primary color
- Provenance comment tracking (preserves original token names and descriptions)
- Flexible token input (JSON, Markdown tables, hex lists, natural language)
- Automatic token → ShadCN semantic mapping
- Dark-mode primary lightening for readability
- Complete SKILL.md with mapping rules, examples, and workflow
- Bundled ShadCN Tailwind v4 default template asset
